## 1. 先把“好文章”变成一个可检验的问题

文章的价值来自解决了什么未知问题、改变了什么判断。美学帮助读者看清这一点；本库不能用成功发表的样本推算编辑录用概率。

先写四句话，再选图：

1. 现有解释为什么不足：给一个具体矛盾或限制，不写“能源危机很严重”作为唯一缺口。
2. 我们改变了什么可控变量：分子取代基、界面距离、工作态、供料或脉冲历史，不能只是换了一个材料名字。
3. 哪个观察真正区分旧解释与新解释：产物切换、低负载仍保留趋势、保持—重置闭环、换底物后收益消失等。
4. 在什么条件内结论成立，什么结果会推翻它。

例：E180的核心不是“小颗粒吸得更多”，而是脱客体后开放相能保持、能受控关闭并重开，且更小尺寸可能不能重置（Fig.1–4，物理页2–4）。E173不是“电流更大”，而是主要产物从甲酸转为CO，迫使解释面对竞争分支（Fig.4–5，页4、6）。E179的关键词是**场的空间分布**，所以需要截面电势及导出电场，单独一个分子偶极数值兑现不了标题（Fig.3，页4）。

写创新时分别说明：新材料身份、新可控方法、新现象、新解释、新应用边界。五者可以关联，但不能用新材料名自动替代新科学问题。

## 2. 看图的六层阅读法

| 层级 | 必须问的问题 | 应留下的记录 |
|---|---|---|
| 身份 | 原始数据、拟合、计算、概念示意还是借用别人的图？ | 数据类型、DOI、图号、物理页 |
| 坐标 | 横纵轴、单位、分母、参比、断轴、归一化和倍乘是什么？ | 原坐标与所有变换 |
| 比较 | 哪两个对象在同一条件下比较？独立样本是什么？ | 受控变量、共变因素、n的层级 |
| 观察 | 不加机理词，实际能看到什么？ | 方向、大小、时间/电位窗口及不确定度 |
| 推论 | 观察支持什么，排除了什么，尚未排除什么？ | 主解释、至少一个竞争解释 |
| 连接 | 下一幅图为什么必要？怎样的结果会改变结论？ | 桥接句与判别实验 |

一次讲图可用四句：**条件和比较 → 观察 → 有界解释 → 下一问题**。

例如针对E183 Fig.5C（SI06物理页15、17）：

> 在所测电位序列中，作者比较了C–O(H)振动峰面积与含氧产物分电流。两者在所测范围呈相近变化，支持该信号与相关产物通道有关。这个对应尚未建立跨样品通用的强度—生成速率标定，因为覆盖度、增强因子和消耗速率也会改变峰面积。下一步应在匹配光学和电化学条件下独立定量产物，并用时间或进料扰动区分积累与周转。

这比“峰增强，说明反应更快”多出的不是修辞，而是证据边界。

### 不同图的特定读法

- **谱图**：先核波数/能量校准、背景、偏移、归一化和倍数，再谈峰位/面积/线宽；峰出现、物种覆盖和反应通量是三个问题。E153 Fig.4/5须留意对数强度和图注面板指向；E178 Raman轴误写波长，不能照抄。
- **XAS**：XANES相对边位、白线、FT峰、拟合距离和CN分别解释。未相位校正FT峰不是实际键长；平均CN不是唯一位点。SI05表S6的CN14.0±4.0与13.4±3.5明显重叠，不能把小差别叫显著降低。原始χ(k)、拟合、残差、路径、范围和约束应齐备。
- **电镜/AFM**：问标尺、取样区域、颗粒数、视野数、膜厚和色标是否一致。E183两材料尺寸/厚度不同，不应称完全排除几何效应；E182 Fig.3保持同尺度便于对比，但代表图仍不能替代分布。
- **性能图**：总j、分j、FE、产率、转化率和选择性分别列。E154/E173的最大FE与最大分电流不在同一电位。FE上升也可能只是副反应受抑，总j增大也可能全来自HER。
- **自由能/反应路径**：区分吸附能、反应状态ΔG、热力学限制电位和真正TS势垒。E176 Fig.6明确画TS；E183 Fig.5D/F未显示所有TS，不能仅凭上坡台阶改写成活化势垒。
- **分布/重复**：电极、器件、批次、位置、像素各自是谁。E179的器件内3位置不是3个独立器件，不能把4器件×3位置当12个独立样本。误差条说明SD/SEM/CI及其层级；有CI字样仍需确认置信水平。
- **寿命图**：记录电位/电流、产物、维护、补液、停机与失效阈值。SI02六次各1 h换新电解液属于复用；SI08约28 h跨多个偏压段；E179热储、光MPP和常温储存不能合并为热光湿连续寿命。
- **热图/二维地图**：颜色编码定量值还是类别？原始采样点在哪里？插值算法是否制造平滑峰值？E183组成×电位图应补采样点；E179 KPFM上下行量程不同，颜色相同不等于电势相同。
- **概念图/示意图**：每条箭头是已测支持、计算支持还是提议？结构球不能表示实测占据率；箭头粗细不能暗示未定量通量。绘图精细度不增加机理证据。

## 3. 组图以问题排序，形成有方向的阅读路径

每张主图只给一个中心命题。它可含多个证据，但不应同时承担材料身份、最高性能、全部机制和工业化四个任务。面板数由必要比较决定，不设“顶刊必须六图/九面板”的硬指标。

用一张表先安排内容：面板 → 问题 → 数据 → 观察 → 推论 → 替代解释 → 下一面板。没有作用的重复表征可放SI；**决定主结论是否可信的空白、负结果和反证不能因不漂亮被藏进SI**。

| 结构 | 适合的问题 | 主图如何串联 | 本轮范例 |
|---|---|---|---|
| 性能先行 | 有清楚应用瓶颈，读者先需知道收益值得解释 | 收益/窗口 → 公平对照 → 工作态/机制 → 泛化与代价 | E152 Fig.1–3 |
| 工作态先行 | 前驱体不是实际催化剂，争议在结构身份 | 形成过程 → 工况身份 → 产物 → 位点扰动/模型 | E159；E183 Fig.1–5 |
| 变量判别 | 两个解释都说得通 | 变量梯度 → 匹配对照 → 正交扰动 → 解释与边界 | E157；E163低负载检验 |
| 反常现象 | 旧解释预测与观察相反 | 异常 → 排除测量/工况 → 候选解释 → 判别实验 | E160峰强更快下降 |
| 可逆闭环 | 主张记忆、恢复、缓冲或再生 | 定义 → 保持 → 读取 → 重置/再生 → 重复与失败窗口 | E180；参考旧E029 |
| 多尺度链 | 分子设计要连接器件/宏观功能 | 分子/结构 → 界面 → 空间或动力学 → 统计输出 | E179；E182 |
| 综述地图 | 需要跨论文建立可用分类 | 需求 → 机制/变量 → 制备/实例 → 反例和缺口 | E156/E169/E177/E181 |

### 一个具体排版决定怎样服务科学问题

E183 Fig.2（页8）把两材料放左右两列，每列保持“AFM—高度—显微—模型”的同构结构；读者能沿行比较同一证据，沿列理解一个样品。其优点是对照路径清楚，局限是色标、尺度与尺寸不同，必须读数。建议重画时统一可比图的尺度/色标，不能为了整齐改数据范围。

E178 Fig.3（页4）用左右材料、上下捕获/释放成对比较。可借鉴同一问题同一行；原图两列纵标不同，不能用峰高直接讲哪样品更多。

E177 Fig.7有20个面板，适合作综述查阅页；拿来当原创论文主图范式会把问题淹没。综述美学强调分类和来源，原创主图强调比较和判别。

### 桥接句的三种用途

1. **排除**：“上述收益在面积归一后仍保留，因此接下来检查工作态和单位位点行为；比电容不同的可能仍需保留。”
2. **提出不足**：“反应后结构支持相保持，但尚不能确定运行时活性相，下面转向工况谱学。”
3. **预测**：“若收益主要来自前体供给，改用下游中间体后差异应缩小；若来自下游转化，差异可能继续保留。”

不要只写“为了进一步研究，进行了XPS/Raman/DFT”。把为什么这项测量能改变判断写出来。预测必须先于看结果设定，并写清可能存在的替代路径。

## 4. 解释实验现象：先列竞争解释，再选判别动作

| 观察 | 常见但过强的解释 | 仍可能是什么 | 优先判别动作 |
|---|---|---|---|
| Raman峰更强 | 生成速率提高 | 覆盖增加、消耗变慢、增强/焦点/背景改变 | 同步产物定量、功率/内标、时间扰动、反应物切换 |
| Raman峰更快下降 | 活性变差 | 中间体消耗加快，也可能解吸/结构改变 | 同步产物和质量平衡，保留关电/空白对照；参考E160 |
| XPS位移 | 单向电子转移已证明 | 校准/充电、配位、终态效应和不同表面组成 | 校准和重复、配体/金属双方信号、工作态互证 |
| Rct降低 | 特定电子路径更快 | 面积、接触、润湿、拟合模型或电位不同 | 同电位/负载、等效电路依据、残差/重复、面积检验 |
| Cdl增加 | 本征位点更活泼 | 面积/润湿/介电环境变化 | 同几何与质量分母，Cs假设敏感性，独立位点估计 |
| Tafel更小 | RDS唯一确定 | 传质、iR、气泡、覆盖、非稳态 | 稳态分电流、低负载/流量变化、合理拟合区间；E163 |
| KIE明显 | 某一步H转移就是RDS | 多步同位素效应、溶剂/输运和参比变化 | 校正条件、并测目标产物、浓度/电位依赖和模型 |
| FE提高 | 目标产率提高 | HER被压低而目标速率不变 | 同时给目标分电流/产率及副产物 |
| 长时电流稳定 | 催化剂和产物均稳定 | 腐蚀/副反应补偿、不同物种贡献 | 定时产物FE、溶出、工作态、维护与累计产量 |
| 活化后容量/电流上升 | 材料越来越优秀 | 湿润、重构、膜变化、副反应 | 空白基底、收支、重复、状态跟踪；E175 |
| 处理时间有最优值 | 某价态越多越好 | 孔可达性、相损伤、粒径和组分共变 | 保留过处理失败组，正交控制位点与孔性；E176 |
| 负载/流量改变排序 | 电子结构解释失效或成立 | 传质与可接近性支配 | 显式改变浓度/流速/厚度并测产物，保留不同机制区间 |

三步停止规则：先排测量/分母错误；再做最可能改变解释的一个对照；若结果仍不能区分，降低结论强度并记录未决点。不要为了一个偏爱的故事追加一长串同样不能区分假说的表征。

具体到E165，Fe0是牺牲电子来源；看到硝酸盐转化不能描述为无外部投入的催化电子循环。E167的光、Pt和牺牲剂也属于系统输入。任何“可持续”“无能耗”“可再生”都应问完整收支和循环再生路径。

SI04还提醒另一个容易被忽略的环节：**先平衡净反应**。其方法写CO进料，但部分FE电子数用CO2口径；纯CO+2NO3−生成尿素净14e，而CO2口径为16e。应先确认实际碳来源及记账约定，再复核FE，不能自动改作者数字，更不能把这一疑点当作已证实错误。详见[SI04审计](si_audits/SI04.md)。

## 5. 画图和配色：让同一变量始终是同一含义

这些是本库建议，不是从论文画面反推的作者软件或期刊偏好。正式成图按用户要求用图形软件，保留原生工程；数据处理可用脚本，最终数据图用Origin，组图/示意用PowerPoint或矢量原生工具。

### 色彩语法

- **类别**：样品用有限离散色，同一材料在全篇颜色和顺序固定。建议四组：深灰`#4D4D4D`、蓝`#0072B2`、橙红`#D55E00`、紫`#7A5195`，同时配方/圆/三角/菱形；对照不必总黑，但应稳定。
- **序列**：时间/浓度用亮度有顺序的同色阶，例如`#DCEAF4 → #8FBBD6 → #3C88B5 → #155A85 → #073B5C`。浅色适合填充，不适合细线和小字；必要时直接标时间。
- **正负变化**：以物理零点为中心用蓝`#2166AC`—近白`#F7F7F7`—橙`#B35806`，注明零点和两侧单位。无正负/中心意义的数据不强行使用发散色。
- **结构图**：原子色遵从明确元素图例；样品颜色与元素颜色分开。Cu橙、O红等结构语义不能直接拿来表示样品优劣。机制中同一中间体固定外观与缩写。
- **二维数量图**：优先感知连续、亮度有序的色图；能用单调色阶时避免彩虹。类别色不能伪装为连续定量色。

所有组合需检查色觉缺陷和灰度可读；本库给的是候选色，**没有宣称每个搭配在任何背景/线宽下均通过无障碍认证**。最终需看实际输出，保证图例、点形和线型能独立区分。色板可直接导入[CSV](story_palette_presets.csv)。

### 数据图的最低可用信息

先设最终物理尺寸，再设字体和线宽。读图要能回答：测了谁、在什么条件、何种单位、几个独立样本、中心值/误差是什么、是否处理过数据。常用7–8 pt是工作预设，不是每本期刊统一要求。大画布原生36 pt缩小后可能只剩很小文字，需按最终尺寸计算。

| 图型 | 应突出 | 应避免 |
|---|---|---|
| FE/产率随电位 | 数据点、误差、共享电位网格和副产物 | 只放总电流，把不同电位最值拼一组 |
| 条件系列谱图 | 原始/处理版本、偏移说明、谱峰归属证据 | 每条任意归一却比较面积、漏倍数、过度平滑 |
| 重复比较 | 独立点＋中心值/区间及n | 只有柱高、把像素当独立重复 |
| 结构与显微 | 同尺度比较、局部放大有位置连接 | 改长宽比、无标尺、单一漂亮视野替代统计 |
| 理论能图 | 参考态、坐标、计算条件、状态/TS区别 | 把反应自由能台阶画成未计算的TS曲线 |
| 时间稳定性 | 真实时间、维护标记、产物与累计量 | 隐去停机补液、把循环数写小时、用断轴掩盖段长 |
| 文献比较 | 同条件分层、分母说明、双指标权衡 | 3D柱遮挡、无条件“世界第一”、只挑一个指标 |

期刊要求与软件步骤另见[执行文件](原生软件与期刊图形规范_2026-10-26.md)。封面艺术、TOC和数据图承担不同任务，不将封面的CMYK、尺寸与装饰要求移植给正文图。

## 6. 标题、摘要、正文和图注必须兑现同一个承诺

标题是论文最短的证据承诺。标题写“界面位点选择性”，正文就要有界面身份和位点区分；只证实性能就用性能层级的题目。摘要顺序建议：具体问题 → 可控策略 → 关键对照/观察 → 有条件解释 → 有边界意义。性能数字附条件和指标身份，不把冠军、均值、稳态及最大寿命合并。

结果段按“问题—观察—解释—边界—下一问题”写，首句先说本段需要解决什么。图注用于独立识别样品、方法、条件、缩放和统计；正文用于讲它改变什么判断。避免正文重复图注的技术清单。完整示例见[标题工作坊](标题与证据强度工作坊_2026-10-26.md)。

图注至少核对：面板字母与真实内容、样品名、单位/分母、偏压参比/iR、误差与独立重复、基线/偏移/倍数、原始/计算/示意身份、标尺与色标、引用/改编许可。E153/E171/E175等存在面板指向问题，是对本库的核对训练，不是可以照搬的排版标准。

## 7. 怎样迁移到PyCEE–CuNi：先做证据图，不预设唯一故事

下面是**研究与写作规划**，不代表已见用户全部原始数据，也未修改现有正文/SI/组图或原生文件。

先把核心问题写成可竞争假说：PyCEE可能改变电子/配位环境，也可能改变分散、润湿、局域反应物/水环境、工作重构、面积及传质。Cu/Ni可能分工，也可能只改变相/位点分布。不能把所有改善同时归于“电子调控＋供氢＋协同＋稳定化”。

| 拟主图任务 | 必要证据 | 关键反证/缺口 | 能写到什么程度 |
|---|---|---|---|
| 材料身份与可控比较 | PyCEE身份、真实Cu/Ni组成、相/形貌/负载及批次 | 无修饰、C60/配体结构对照及面积/分散差别 | 材料和比较成立 |
| 目标反应的收益/代价 | 同条件NH3 FE、产率/分j、NO2−及H2、重复与空白 | NO3−/NO3–N口径、回收/基质干扰、法拉第闭合 | 有限条件下性能改善 |
| 工作态和结构演变 | 与性能匹配的时间/电位XAS、Raman及前后表征 | 空气重氧化、平均信号混合、初始结构≠活性态 | 支持某类工作态变化 |
| 反应过程与竞争路径 | 底物/中间体替换、浓度/流动/同位素扰动与产物定量 | *H库存不等于有效供氢；峰强不等于速率 | 有界路径解释 |
| 机制收束与边界 | 能解释正/负结果的最简模型、失败区间、耐久收支 | 替代解释未排除则降级用词 | 设计原则或待验证模型 |

优先级按“会不会改变核心结论”排序，先核材料身份、产物定量与公平比较，再补真正能区分机制的实验。重复电极跨批次、随机化测试顺序、控制电解液/仪器漂移；先少量可逆试验估变异，再决定正式样本量，不把n=3当自动充分。

Raman强度直接反映形成速率仍保留为**作者工作假设/待验证**。E160的更快衰减与E183的峰面积相关共同说明：同一强度现象可能有多种动力学解释。E182可支持分子身份与原有PSC用途，不能直接补写用户样品的Cu/Ni配位或NO3RR反应事实。
