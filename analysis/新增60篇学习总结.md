# 新增60篇：证据更新与可复用判断

2026-10-16。本批 E032–E091，共60个不同论文身份，与原31篇不重复，累计91篇、279条页级论断。来源为49份既有本地/Zotero正文和11份出版社开放获取PDF。包括57篇原始研究与3篇综述；光催化、热催化和耦合反应只作为明确标注的相邻设计参考，不混作NO3RR实测证据。

阅读为机制、结果、条件和边界的重点句段阅读，逐卡记录定位；不是60篇正文/SI逐字通读。综述引用的几十篇原始研究没有另算已读。文本/原图核查分开，本批另目视核查E054 p.4、E055 p.7、E071 p.5、E076 p.3、E088 p.6、E090 p.6。

## 一、这次真正改变判断的八条规则

| 判断 | 新证据入口 | 对以后工作的改变 |
|---|---|---|
| 更强H信号不等于更多H流向NH3 | E036、E046、E055、E074、E075、E083 | 先辨水/乙二醇来源、吸附/次表层/自由基种类，再核产品相关速率与HER |
| 更低Rct不自动表示更好目标反应 | E044、E055 | E055在部分电位响应较慢却更偏深还原；EIS按反应贡献/传质区间解释 |
| 同一修饰的正效应可随底物反向 | E051、E053、E077 | 聚合物对CO2RR和CORR相反；胺化体系中抑NH3可能是好事，先定义目标 |
| 单原子不自动兼具最高面积产率 | E049、E057、E063、E077、E089 | 位点选择性、金属装载和电极输运分开；TOF先查可及位点计数 |
| 阳离子富集不是通用定律 | E039、E042、E070、E091，与旧E002/E022对照 | Ru论文提出排开水合K+，有些体系则富集；保留表面、溶剂和浓度依赖 |

| 维护、底物浓度和系统边界决定“稳定/高效” | E034、E035、E050、E052、E068、E071、E084–E088 | 换液/清洗/加压、两极产物、不同电流时长分别写，不能拼成一组最佳器件 |
| 顶刊数字仍要过单位/电荷校验 | E057、E059、E062、E063、E071、E076、E088、E090 | 保留浓度基准、重复数、缩放和待核矛盾；不以期刊声誉替代计算 |

## 二、供氢机制不能再只画一条箭头

至少分四层：H从哪里来 → 暂存在哪种状态 → 如何到达/参与目标反应 → 与哪些通道竞争。E036的光催化H主要来自EG脱氢，不应改写为水解离；E074区分表面吸附和次表层氢化物；E055用外加溶解O2作为间接探针，DMPO–OH还可含ORR及含氮氧化贡献；E046说明可检出H物种而目标有机加氢仍主要按PCET解释。

因此，把一个EPR峰、CV峰或Bode特征命名为“氢溢流证据”仍不足够。E075中供氢探针继续增加而FE下降，E083中加入NO3后H信号消失却被作者解释为消耗增强，都要求产物速率和竞争产品参与判断。迁移到实际CuNi时，应先建立同条件NH3 FE/分电流与真实对照，再选择一个有区分力的供氢扰动；不强制堆叠全部高级表征。

## 三、分子修饰：电子变化、保留和可及性的竞争

E051对CO2与CO还原的反向作用说明“更亲水/更富电子”不是完整机制。E065的分子F取代还改变脱金属/簇形成；E066的C60改变局域无定形Ru–O结构；E061的聚合C60网络具有不同于单体的Raman特征。与旧E005/E026–E029共同构成角色地图：合成助剂、空间锚定、电子调节、反应中心、可再生介体及局部结构构筑，不能全部统一为电子缓冲。

E076明确承认EXAFS的N/O/C散射指认有主观性、距离借助DFT，Cu参考曲线还缩放×0.4。这是结构模型边界的直接实例；小峰移/好拟合不能直接写成唯一键合已证明。E072的间隙电子亦应保留其模型和测量定义。

对实际分子修饰体系，优先分辨：分子是否保留、工作态是否改变、可及面积/润湿/传质是否代价过大。E035中BET更大不意味着电极更好，E055中过厚凝胶阻塞传质，E077的低负载单原子虽更选择耦合却产率低于颗粒，都说明结构层级必须分开。

## 四、冲突记录要进入写作，而不是被平均掉

- **晶面排序**：E054的受控金属Cu单晶在其碱性条件下支持Cu(100)>Cu(110)≫Cu(111)。E041回顾的早期排序并不一致；模型的OH、水供质子、构型和实际工作态可改变结论。不可写“文献一致表明Cu(111)最佳”。E048的Cu-MMT晶面是另一晶相。
- **阳离子作用**：E070把K+稳定与界面水联系，E091则提出水合K+远离有益。优先对比反应环境与测量定义，不把相反结果当作平均最优距离。
- **同位素与材料氮**：E056用标记、洗涤、换底物及再释放检验晶格再生。单独检出材料氮贡献尚不能区分催化循环与材料被消耗，仍需库存/周转检验。
- **碳/氮来源**：E040以离子液体稳定为由未做13CO2，不能把“作者认为无需”升级为已验证来源；E060的部分优化图用浓氨液，不能把所有丙氨酸都直接算作硝酸盐供氮。
- **定义**：E057的100%相对纯度并非100%甲酸质量分数；E066的conversion公式按主产物量定义，更接近产率；E076的coupling efficiency是自定义指标。

## 五、数值校验的最小能力

氨分电流与产率在同工况、同面积下应满足：

`j_NH3(mA cm−2) = rate(mmol h−1 cm−2) × n_e × F / 3600`

NO3→NH3用8电子，NO2→NH3用6电子，NO→NH3用5电子；混合进料须根据真实转化收支处理。质量产率先按NH3或N的实际质量基准换算。工具`scripts/check_faraday.py`执行这一步，不替代实验测量。

| E085，NO，10.5 mmol h−1 cm−2 | 约1407 mA cm−2，对报告1415.3 | 接近1%内；符合四舍五入量级 |

## 六、用于写作、绘图、实验的明确路线

**写作**：先给真实产品差异及条件 → 再给同工况工作态 → 用一个能排除替代解释的对照/扰动推进机制 → 列出未支持部分。每条主张绑定claim ID与DOI/PDF页，综述只作背景地图，关键结果回原始研究。E058/E064/E078是综述；并未替用户材料测得价态、局部pH或氢溢流。

**绘图**：同工况FE与分电流并列；Raman/IR按各自选择规则和增强条件处理；ΔG图与含真实TS的势垒图区分；模型结构标示假设；稳定性标换液/清洗/压力。E054值得借鉴把各晶面三种产物同时呈现；E076提醒缩放不能省略；E052提醒串联槽和两极产品不能藏在一个“产率”中。

**实验规划**：先确认真实CuNi对照、装载和产物定量，再在电子/工作态、供氢利用、润湿传质三个解释中选择一个能改变判断的分歧。批次为独立实验单位，时间顺序/仪器作区组；重复读数不替代独立样品。精确合成与操作条件必须来自实际记录。NO2RR、同位素、原位XAS等是按问题选择的工具，不是本轮自动生成的必须补做清单。
