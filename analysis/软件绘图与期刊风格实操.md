# 电催化绘图：软件、最终尺寸与证据表达

核查日期：2026-10-18。基于新增30篇的指定关键图、正文重点句段和下列官方资料。逐篇案例见[新增30篇索引](新增30篇论文与读图索引.md)。本指南给可执行的复现路线；除卡片明确披露外，不代表原作者的软件。

## 先决定图回答什么

一张主图先写一句可被数据推翻的结论，再选择面板。材料“更复杂”和渲染“更炫”都不是科学贡献。建议依次回答：干预了什么→工作态是什么→产品及电荷去了哪里→哪个替代解释被排除→在什么条件下失效。不是每篇都需要五张图，面板应随实际问题安排。

E109的产率近似而FE提高，适合把两者并排；E115的形貌—衍射对应矩阵适合研究重构；E099适合用多电位能级图提出模型边界。不要把这些不同问题都塞进“合成示意+TEM+最高FE”的固定模板。当前选样只有已发表成功案例，不能据此推算某种外观提高录用概率。

## 软件怎么选

|任务|建议软件|必须保留的可编辑来源|什么时候用|
|---|---|---|---|
|LSV、FE、产率、分电流、Raman叠谱|OriginPro；批量时Matplotlib|OPJU/模板及原始工作表；或CSV+Python脚本|需要统一坐标、误差与批量更新|
|多面板布局、箭头、局部放大|Illustrator；免费方案Inkscape|AI或SVG，文字保持文字|统一间距、字级和矢量元素|
|分子、COF连接与反应式|ChemDraw|CDX/CDXML|化学连接、价态、立体关系必须准确|
|晶体、吸附构型、电荷密度|VESTA；分子几何可用Avogadro|CIF/POSCAR/优化坐标、等值面参数和项目|展示真实结构或计算结果|
|SEM/TEM、mapping、尺度与线扫|Fiji/ImageJ及仪器分析工具|原图、标定、ROI、处理日志|添加真实尺度、可追溯裁切/统计|
|XAS/XPS拟合|Athena/Artemis或适用的XPS专业软件|原谱、背景、约束、拟合与残差|拟合在分析软件中完成，再导出数值绘图|
|空间界面/装置概念示意|Inkscape/Illustrator；确需三维才用Blender|SVG/AI或BLEND及素材来源|解释几何关系，不能替代测量图|

VASP、Gaussian等属于计算工具，不能在不知道实际用途时统称“绘图软件”。E096 U45、E100 U47明确披露VESTA；E103 U60披露自定义Python用于氢键统计。其余软件身份必须以逐卡记录为准，不能从渐变、字体或PDF制作器猜测。

软件能力依据：[Origin导出说明](https://docs.originlab.com/user-guide/publishing-and-export/)、[Origin到Illustrator的SVG建议](https://docs.originlab.com/quick-help/export-graphs-as-ai/)、[Matplotlib保存图形](https://matplotlib.org/stable/users/explain/figure/figure_intro.html)、[字体设置](https://matplotlib.org/stable/users/explain/configuration.html)、[Inkscape保存说明](https://wiki.inkscape.org/wiki/Files%3A_Save)、[VESTA手册](https://jp-minerals.org/vesta/archives/VESTA_Manual.pdf)、[ImageJ空间标定](https://imagej.net/imaging/spatial-calibration)、[Blender输出格式](https://docs.blender.org/manual/en/5.1/files/media/image_formats.html)。这是功能匹配建议，不要求购买全部软件。

## 三个目标期刊的参数

|目标与阶段|核查到的官方正文图要求|本库工作预设|
|---|---|---|
|JACS主图|单栏≤240 pt；双栏300–504 pt；字≥4.5 pt、线≥0.5 pt；栅格线图/灰度/彩色最低1200/600/300 dpi|84.67或177.8 mm；Arial 8 pt；数据线1 pt|
|Angew正文嵌图|单栏≤84 mm、双栏≤178 mm；文字约7–8 pt；嵌入高质量图≥300 dpi|84或178 mm；Arial 7.5 pt；数据线1 pt|
|Nature Communications主图|88/180 mm；线图优先矢量，位图≥300 dpi；白底、统一无衬线字|88或180 mm；Arial 7.5 pt；数据线1 pt|

来源：[JACS指南，2026-10-05版](https://researcher-resources.acs.org/publish/author_guidelines?coden=jacsat)、[Angew Graphics，09/26版](https://onlinelibrary.wiley.com/page/journal/15213773/homepage/graphics-guidelines)、[Nature Communications投稿指南](https://www.nature.com/ncomms/submit/how-to-submit)。工作预设不是官方指定的字体大小或配色；JACS最低4.5 pt也不意味着应该用到4.5 pt。Nature旗舰刊、Nature Catalysis与Nature Communications应分别核查。

TOC另设画布。Angew两份页面横版宽度为110/115 mm，存在差异；示例采用共同允许的55×50 mm，不拿TOC尺寸当正文图尺寸。[Angew Notice，10/26版](https://onlinelibrary.wiley.com/page/journal/15213773/homepage/notice-to-authors)。投稿前再核目标文章类型、最新模板和返修要求。

## Origin → SVG → 组版的实际步骤

1. 导入CSV，把样品、批次、潜位、FE、总电流、面积和重复编号分列。原表只读另存，派生量在新列计算。同一电位、同一电解时段的`j_NH3 = |j_total| × FE_NH3 / 100`必须成对；不能将LSV电流配另一轮电解FE。
2. 每个独立电极先出一个值，再按独立重复算均值与SD。重复读取一份溶液不是独立电极。曲线点用不同形状/线型，控制样灰，目标样蓝，其他参照橙；全稿同义同色。
3. 在Plot Details设置数据线约1 pt、符号约3–4 pt；轴线约0.6 pt。页面先定最终宽度，按7.5–8 pt设置文字，再检查长单位是否挤出边界。不要先做很大再任意缩小。
4. FE与产率优先分面；确需双轴时轴名和序列一一对应，显示真实量纲。光谱保留原始曲线、位移/归一化/倍数说明。XPS分峰附背景和残差，不能以漂亮拟合代替可识别性。
5. 保留OPJU和模板。`File → Export Graphs (Advanced)`导出SVG供组版；另导出嵌入字体PDF核对文字和公式。SVG文字保留为文字。Origin官方推荐SVG用于Illustrator编辑；不要截屏后再当矢量文件。[导出设置](https://docs.originlab.com/origin-help/settings-in-expgraph-dailog/)
6. 在Illustrator/Inkscape创建最终尺寸页面，导入子图，按3–5 mm工作间距对齐；共同坐标和图例只保留必要次数，面板字母统一位置。不得在组版软件中拖拽数据点、抹掉谱峰或局部改亮度。
7. 输出保留文字的SVG母版和字体嵌入PDF，栅格按目标期刊与图类型选择。白底、100%尺寸检查及灰度检查后，再嵌入Word；关闭会降低分辨率的图片压缩。SVG与PDF各自打开一次核对上下标、负号、µ和Å。

## 结构与示意的具体路线

真实吸附结构：优化坐标→VESTA设原子半径/键/相同观察方向→记录等值面与颜色→导出→Inkscape加统一标签。电荷密度正负等值面值应对称并注明定义；不能为了好看换成另一结构。结构中原子坐标有物理意义，Blender只负责必要的表达与照明。

概念图：先画“对照界面 / 修饰界面”两个简图，只保留与假设相关的水、底物、位点和产物。测得的量用实线，待验证过程用虚线并加“proposed”；箭头宽度无通量标定时不作定量。C60若未证明是活性位，不画成直接断键中心。机制图应能回指卡片/实际证据，不能用渲染填补机制缺口。

显微图：打开原始文件→确认像素尺寸/标定→保存ROI与裁切记录→添加尺度条→按相同规则比较。图像强度三维表面只是强度（E119），不能把纵轴改成真实高度。禁止凭已发表图截图重建“原始数据”。

## 可运行训练包

运行`python scripts/make_figure_examples.py`。输出在`figure_examples/generated/`：同一组合成训练数据的JACS、Angew、Nature Communications三个参数版本，各有SVG/PDF/PNG，以及灰度预览和55×50 mm的可编辑TOC草图。SVG、脚本和CSV随仓库提供；PDF/PNG由脚本生成，保留在本地。示例每张都标训练/合成，不是用户测量、论文重绘或实验证据。

依赖：Python、NumPy、Matplotlib、Pillow、pypdf；可用`python -m pip install -r figure_examples/requirements.txt`。再运行`python scripts/preflight_figures.py`，检查物理尺寸、SVG文字、字体嵌入、PNG像素及画布外文字。自动检查无法代替人工核对科学内容，也不会宣布“保证录用”。本次验证结果见`analysis/figure_validation.json`。

## 最值得学习与应改进的案例

|案例|可迁移方法|保留的批判|
|---|---|---|
|E093、E110、E115|同条件、双元素、前后或同位置对应，支持工作态叙事|不同测量的误差层级不相同|
|E095|把测量空间场、模型映射和分布相连|模型映射不能标为直接实测能量|
|E099、E101|由理论提出可检验的电位/pH/配位预测|自由能、动力学与实验趋势各有适用范围|
|E109|FE与产率并列，直接表达电荷分配变化|不能虚构产率全面提高|
|E111、E112|长时间曲线主动标换液|三纵轴可改共享时间三轨|
|E092、E107|保留多条件比较与误差|删装饰3D柱、过重网格，遵循当前官方指南|
|E121|把基底副反应与覆盖效应纳入机制|箭头宽度和覆盖示意不是实测通量|

建立自己的风格文件：样品命名/配色表、最终尺寸、字级、线宽、图例、光谱偏移规则、原图处理规则及导出日志。风格应减少读者判断证据的成本；它不能把缺乏创新或证据的文章变成顶刊文章。
