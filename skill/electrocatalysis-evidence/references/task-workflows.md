# Task-specific application

## Writing

Build the argument from actual results to bounded interpretation: question → measured difference → relevant working-state evidence → discriminating test → remaining alternatives. Search conflicting evidence as well as supporting precedents. Local manuscript methods come from actual records; literature supplies neither missing measurements nor exact unrecorded synthesis conditions.

For a molecularly modified CuNi sample, distinguish possible wetting/area, electronic/working-state, and proton/H supply effects. E003 is Ni4N/Cu, E004 is CuCOF, E005 is C60/Cu2O CO2RR, E028 is Pd ethanol oxidation. None proves the same mechanism in CuNi. Confirm actual sample identity and real control treatment.

Useful comparisons: E001 associates reduced Cu with NH3 under its conditions, E015 retains interior CuOx while external Ru is active, E029 stabilizes mixed Cu in urea coupling. These are conditional findings, not a universal optimum Cu valence. E026's direct C60 activity and E029's mediator interpretation must retain their different environments.

Preserve incompatible numerical reports (E010/E025) and proof metadata gaps. Cite DOI and claim/PDF page. Verify current journal instructions only when preparing a specific submission. Mark hypotheses for author review; do not upgrade them by repeated citation.

## Figures and spectra

Choose a scientific question per panel before styling. Material identity → same-condition product allocation → working state → one distinguishing mechanism test → stability is an adaptable sequence, not a mandatory characterization list. Use editable raw data and dated versions; develop original figures rather than copying paper images.

- Raman: E001 pp.7–8 supports 1128/1266 cm−1 NO2-related assignments in its context; this library did not verify 1040 cm−1 from E001. Match technique and overlaps before transfer; IR/ATR-SEIRAS labels are not Raman evidence.
- Check laser/acquisition, baseline, normalization, plasmon/reconstruction enhancement and multipliers. A steady intermediate signal can rise through faster formation or slower consumption; independent product kinetics is needed for a rate claim.
- XPS/XAS: keep Cu0/Cu+ ambiguity in Cu 2p distinct from Cu LMM/other evidence. State probe depth, potential and time. Small edge shifts alone do not establish unique Cu–C coordination (E005).
- Calculations: label ΔG, adsorption energy and actual transition-state barriers separately; PDS is not automatically RDS. E030 Fig.4 fixes the framework after adsorption; Fig.5 relaxes all atoms. Record constraints before comparing.
- Dynamics: E016 pulse potentials are Ag/AgCl, E029 CV Fc/Fc+ and performance RHE. Preserve both pulse durations/charge accounting, not just the cathodic potential.
- Stability: mark feed replacement, electrolyte refresh, electrode treatment and decay. E018 has nine replacements in 100 h; E031 needs backside PTFE and refresh. E024's paired anode degrades despite cathode cycling.

## Experiments

Write competing hypotheses and their distinct predictions first. For each proposed experiment record the deciding observation, confounders, actual resources and stopping rule. If both hypotheses predict the same response, choose a more discriminating perturbation.

1. Verify product assay and a fair target/actual-control comparison: potential/reference/iR, electrolyte, charge, loading/area, sampling and independent batches. Use a repeatability pilot when variance is unknown.
2. Compare NH3 FE and partial current/yield on consistent bases; inspect H2/other products as relevant. Total-current improvement alone does not show enhanced ammonia production.
3. Select one feasible perturbation: modifier amount, potential, controlled pH/cations, isotope substitution or charge-then-substrate response. Do not require all of them. Control the consequences introduced by the selected technique.
4. Add mechanistic spectroscopy only when it resolves a remaining ambiguity. KIE, spin trapping, H-UPD and poisoning are indirect and can alter the system. E020 KSCN interferes with indophenol blue; validate the assay before interpreting inhibition. E021 pre-added NH3 needs background and gas/liquid balance.

Independent synthesis/electrode batches are experimental units; repeated readings on one electrode do not create independent replication. Randomize feasible run order and block date/instrument/batch when needed. Sample size depends on actual variance and the claim; this library supplies no universal n.

Do not make a toluene mock control or NO2RR performance series mandatory for the current CuNi scope. Suggest them only if they resolve a chosen question. Do not rename a project's staircase potentiostatic current records conventional NPV merely because a source uses that acronym.

## Add and revise evidence

Review relevant complete sections, not just abstract/search hits. Record focused passage versus main-section reading honestly. Pair SI by title/authors, verify printed DOI, hash source identity and locate each claim. Text extraction is not reading; text review is not image inspection. Negative or conflicting outcomes must affect the synthesis.

New records require: card ID, DOI/doc ID/hash, title, actual read scope/pages, conditions, page-level claims with evidence type, mechanism, limits, and writing/figure/experiment use. Keep author observations, author/model interpretation and transfer advice separate. E006–E031 claims initially summarize author text; category detail should be refined from the actual passage before a strong mechanistic claim.

Add papers in a dated batch, maintain old versions and run library validation. Validate counts, DOI uniqueness, locator bounds, meaningful retrieval, source identity and optional full-page access. Full-text/PDF/source packet/image artifacts remain outside the portable repository. No native model memory or scheduled job is created by updating cards.
