# Manuscript arguments and scientific figures

Resolve the library via `library-location.md`. Read `analysis/新增30篇学习总结.md`, `analysis/软件绘图与期刊风格实操.md` and the relevant cards, not all121. Consult `analysis/journal_profiles.json` for dated requirements; verify the exact journal, article type and submission stage again before actual submission.

Keep three layers explicit: official requirement, observed published example, and our recommended reproduction workflow. Published figures are not evidence of an editor's private preferences or reason for acceptance. Success-only sampling cannot estimate acceptance effects. A palette or 3D rendering cannot replace scientific novelty or causal evidence.

For each main figure, state the claim, which panel supports it, the strongest alternative explanation and what remains uncertain. Match source data to sample, batch, potential/reference/iR, area/loading, electrolyte, assay and time. Show independent repeats and define SD/SEM/CI; technical repeated readings do not become independent electrodes. Do not splice maximum FE, rate, current or lifetime from different conditions. Run Faraday checks before comparisons.

Select software by task and this user's native-source requirement: Origin `.opju` for final data plots; PowerPoint/vector-native sources for schematics and assembly; ChemDraw for chemical connectivity; VESTA for coordinate-based structures; Fiji for calibrated microscopy; Blender only when spatial concepts benefit. Python may process data and perform checks but is not the default final figure renderer. Authors' software is known only when explicitly disclosed: E096 U45 and E100 U47 name VESTA; E103 U60 names Python for hydrogen-bond analysis. Computation software does not establish the plotting tool. Unreviewed SI remains unreviewed.

E092–E121 each have ONE visually inspected figure recorded in `visual_review` and `analysis/visual_reading_receipts.json`. Use the recorded figure label/ID; do not infer all figures are checked. E099 is theoretical NO3-to-NO2 work; E097/E121 target hydroxylamine. Source units in these cards are JATS paragraph/caption indices, not PDF pages. Use `--source-units`, not `--source-pages`.

Historic outputs of `scripts/make_figure_examples.py` are synthetic archival training examples; do not use that renderer for this user's new scientific figures. Never use synthetic spectra as manuscript measurements. New real-data figures need separate versioned inputs, native projects and validation. Set final physical size before fonts/lines; retain vector text where possible and inspect at100% plus grayscale. Preserve original source images, calibration, crops, normalization/offsets, fits/residuals and editable files. Schematic arrows must distinguish measured support from proposed mechanisms. Current case-based methods and dated journal sources are in `analysis/原生软件与期刊图形规范_2026-10-26.md`.

Current verified width limits and exact journal links are in the2026-10-26 native-software guide: JACS up to240 pt single-column and300–504 pt double-column; Angew84/178 mm. Historic Nature Communications88/180 mm values are design presets, not a newly verified specification here. Fonts7.5–8 pt are OUR working presets; do not call them universal publisher requirements. Angew landscape TOC width conflicts110/115 mm between two official pages; use shared55×50 mm or confirm latest template. Do not transfer flagship Nature rules or cover sizes to these main figures.

Useful patterns: E109 FE improvement at similar rate; E115 precursor-to-working-state comparison; E095 model-derived maps explicitly labeled; E111 maintenance marked in stability; E099/E101 potential/pH-dependent predictions. Avoid copying decorative3D bars (E092), heavy grids (E107), ambiguous multi-axis displays or unsupported peak assignments just because they were published.
