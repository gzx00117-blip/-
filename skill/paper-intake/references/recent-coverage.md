# 近三年覆盖与续读

用于近三年的项目、期刊或专题阅读。本地清点、主动检索和原文阅读可以分批进行，并以同一个 DOI 队列续读。

## 建立覆盖范围

1. 默认从请求当天往前滚动 36 个月，记录起止日，含两端。优先采用出版社首次在线发表日期。用正式刊期或仅有年份/月份的记录注明精度，边界不明确时留待核。预印本与正式版关联保留，排除状态变动另行记录。
2. 焦点来自请求，既有课题用来定优先级。用户说全部电催化时，覆盖不同期刊、材料和反应，至少将 NO₃RR/NO₂RR、CO₂RR/C–N 偶联、HER/OER/ORR 和用户指定的其他支线分别构建检索组。富勒烯/分子修饰、Cu/Ni、工作态及界面是可与反应交叉的标签。优先读用户项目密切相关的结果，保留后续队列。对用户仅问“这个专题”的请求直接限定专题。
3. 在本地读取授权目录和 Zotero 范围。先找 Zotero 的条目、附件、链接文件和已有 PDF 目录。扫描识别的目录与实际查询的 Zotero 条目分别记录。按 SHA-256 找文件副本，按源首页/出版社核实的 DOI 匹配正文；同一 DOI 的不同版本、主文和 SI 保留独立文档身份。无 DOI 或 DOI 有冲突时保留记录，查标题、第一作者和年份。日期按出版信息核对。

## 主动检索和全文

- 同一反应用名称、缩写、产物、关键材料的同义词组检索。用综合索引如 Crossref 或 OpenAlex，另用出版社、期刊目录、机构库、PubMed/PMC 或引文链补齐。记录检索日期、实际查询、起止时间、来源、分页上限和未检索完的分支。无法分页的网页搜索作为候选补充。声称已查完某个期刊范围时，核对目录/文章索引并记录排除项。
- Crossref 可以用出版日期过滤和 cursor 分页。按时间或期刊分片，记下是否到末页、服务错误和后续重试范围。高召回检索的结果待核实题材和稿型。阅读之前仍须核对源页 DOI/标题，有时摘要与在线全文的可访问性不同。[Crossref 过滤说明](https://www.crossref.org/documentation/retrieve-metadata/rest-api/rest-api-filters/) · [分页说明](https://www.crossref.org/documentation/retrieve-metadata/rest-api/tips-for-using-the-crossref-rest-api)
- 合并去重后按「本地/授权附件 → 公开出版社全文或机构存档 → 可访问预印本 → 摘要」获取。核对正文、图表和 SI 的实际访问，不从搜索摘要推断视觉风格。只有摘要的论文可先分析摘要，将需要的材料和来源记录入队。阅读全文时回到 [单篇流程](../SKILL.md) 和 [图文与审稿分析](writing-figures-and-review.md)。
- 每个批次给出最终窗口、清点的文件数、已确认的文章 DOI、疑似 SI/待核身份、正文可访问数、新读的实际范围、未处理或受限项。检索命中、文本提取、正文可访问和已经精读各自计数。开放网络的覆盖声明限定于实际使用的索引、期刊与检索范围。

## 本地对账工具

`scripts/reconcile_sources.py` 使用 Python 3.10+ 标准库。传入一个或多个 `--pdf-root`、已知语料的 `--inventory`、既有 `--cards` 与主动检索整理的 `--online`。填写查阅窗口 `--from`、`--through` 和新的本地 `--output`。脚本统计本地 PDF 和已知身份，输出合并 DOI 队列及此前阅读范围。新 PDF 或身份有冲突的文件后续回首页匹配。脚本可在 skill 安装目录运行。

`--online` 是 JSON 数组。条目用 `doi`、`title`、`journal`、`source_url`、`access`、`published_online`（核实首发时）或 `date`（年月日、年月或年份）。新识别的本地文件可用含 `sha256`、`doi`、`identity_status: "verified"` 的 `--inventory` JSON 数组补录。若首页或出版社明确证明两 DOI 属同一篇（例如双语版本），用 `--aliases` 传 `alias`、`doi`，保留来源。继续分批读时，用 `--receipts` 导入带 `doi`、`scope`、`source` 及可选页/图/笔记位置的 JSON 数组。每次生成新快照，并显式传入旧阅读记录，以便新增或更正时核对历史。没有 DOI 的文章留在来源待核项，继续按题名、作者及日期查。

把本机路径、原始全文、补充材料和用户自己的实验记录保存在本机。将通用流程、可公开的引文与原创分析维护在技能或知识库。
