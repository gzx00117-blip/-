# 写作、图形和审稿分析

学习时先从原论文记录证据怎样说服读者，再转成自己的数据结构、文字和图。标准精读可给每项一句，指定学习某一项时展开。全文不可访问时，标题/摘要可分析，图序、颜色和布局按实际目视材料判断。

## 文字怎样推进

1. **标题与摘要。**摘出可检验的新发现、手段、体系和适用区间。标记标题主张在正文首次由哪两项证据兑现。摘要按「具体未解问题 → 干预或对照 → 同条件结果 → 化学意义」重构。选择性、速率、价态和因果写到各自能支持的强度。
2. **引言与结果。**画出每段回答的问题，用上一段暴露的竞争解释带出下一组实验。结果段先交代比较，再写观察，最后写有依据的解释。可直接报告相关性。若研究的关键是某个中间体或者结构，可用“哪一步改变、怎样知道”来串联。
3. **图注。**先交代任务和样品，再标各分面、参比、归一方式、误差定义、独立重复和特殊工况。正文解释比较的科学含义。关键统计和会改变解读的对照给出可追溯的位置。

## 画什么图

| 科学问题 | 推荐图形和面板 | 要核对的条件 |
|---|---|---|
| 改性改变了什么结构 | 构建示意+同倍率显微/分布图+具定量信息的谱或结构指标 | 形貌和负载是否匹配，证据来自初始、运行中还是反应后 |
| 选择性是否提升而且产物做得更快 | 同一电位横轴并排画 FE 和产物分电流；有重复时尽量显示独立点和误差 | 气液取样窗口、面积、电荷、参比和 iR 一致 |
| 增益来自哪个反应步骤 | 同条件分面比较独立底物、空白和目标产物；用时间轴或点图显示干预前后 | 关注替代解释在这组干预下是否有不同预测 |
| 谱峰是否随条件或干预系统变化 | 电位点少用叠谱和指定峰定量，点多用热图并辅以代表原谱；给出空白或参考 | 基线、归一、曲线偏移、色条和峰位置；光谱强度的解释取决于探测机制 |
| 机理模型解释了什么 | 示意图与支持它的工作态信号或干预放近；计算能量图写清状态和能量定义 | 推断路径可用虚线；热力学与过渡态势垒分开 |
| 稳定性或工况范围 | 连续时间序列标注换液、停机、重启；跨条件用分面或经核对的矩阵 | 同时显示目标分电流或产率，并给每段实际工况 |

主图每组一个问题。面板顺序优先「对照可见 → 读数可比 → 足以区分解释的证据」，随后让图注和正文使用同样顺序。复测、完整拟合和辅助验证可放 SI，决定主要结论的对照应在主文可见。不要给用户加上缺乏判别价值的表征清单。

## 配色和排版

- 先写图例的语义映射。同一材料贯穿整稿，同一颜色在同一区域避免同时表示材料和电位。分类变量搭配形状、线型和直接标签；有序强度用明度单调色阶；有零或其他有意义中心时用发散色阶。
- 同类面板的色条、轴域、比例尺和单位尽量一致。独立归一或采集条件影响比较时明确标注。看缩小到投稿栏宽后的字号、线宽、对比度、灰度可辨性和色觉差异。采用该刊现行图稿规范决定导出参数。
- 记录论文图里**实际观察到的颜色用途**和**为用户推荐的色值**。正式制图如已有明确本地偏好，从原始数据保留可编辑项目。对本用户，Origin 保留 `.opju`，示意和组图可用原生可编辑矢量。成稿视觉外观无法唯一识别制图软件。

## 如何回答“这个期刊的审稿人爱看什么”

| 来源 | 能得出的判断 |
|---|---|
| 官方 scope、作者/审稿指南 | 公开标准、适用稿型和对科学贡献或呈现的要求 |
| 多篇接近体系的已发表论文 | 发表案例如何以标题、关键对照、图表和方法完成论证。写样本数、范围和反例；如比较频率，给分子分母 |
| 公开审稿报告与作者回复 | 具体哪位审稿人在第几轮问了什么、作者加了什么证据、问题是否得到处理。从原文件核对后引用 |
| 基于前三种材料模拟审稿 | 提出最可能动摇核心结论的 1–3 个问题，标为推演。各问题给一条现有证据、一项最能改变判断的补证和可写入正文的结果句 |

跨刊比较时优先匹配题材、文章类型、年份、反应和贡献类型，并记录差异。当前试用见[四刊案例](electrocatalysis-journal-cases.md)。增加新文献时可记录「刊物/类型/DOI｜首次兑现标题的文字及图｜面板/配色规则｜源定位｜审稿问题及证据类型｜可迁移到什么场景」。发表样本缺少未录用稿和过程数据时，判断用来挑选叙事重点和补证优先级。
