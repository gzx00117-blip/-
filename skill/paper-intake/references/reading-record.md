# 深读记录

根据问题调整详略。几句话能回答的单项查询直接定位。用于复核、批量比较或后续调用时，保留下列记录。

## 单篇记录

| 项目 | 记什么 |
|---|---|
| 文献身份 | 题名、DOI 或持久来源、版本、文献类型 |
| 阅读范围 | 实读正文小节/页、目视主图/表、SI 文件名及页、不可访问项目。PDF 文件页从 1 开始。页码与印刷页号有偏移时指明口径 |
| 一句话贡献 | 清楚交代作者解决的化学或科学问题和独到的可验证结果 |
| 三到五项关键证据 | 主张、观测/计算类型、量值和同条件对照、源定位、剩余解释或最能区分的干预 |
| 图表串联 | 图的命题、各组面板的角色、最关键的读数、与上一图和下一图的联系 |
| 可迁移应用 | 用户要写作时指出一句主张如何落成证据句。要绘图时指出可复用的组图方法。要规划实验时给最能区分假设的下一项对照 |

需要可追溯卡片时，每条可以写成：**主张**｜**证据类型**｜**具体条件及读数**｜**来源位置**｜**证据边界**。图谱的相关性可直接写入观察栏。机制解释需说明是作者提出、计算支持、实验约束或直接干预。对法拉第效率、电流、材料载量、气体或产率，先确认同一积分窗口和分母再比较。

## 批量和持续学习

- 先按 DOI 和版本识别重复正文，正文、单独 SI 和无 DOI 文件分别匹配；同 DOI 的预印本或先行版如与终版不同，保留差别。跨文献对照时用相同字段记录，并保留关键条件不一致的项目。
- 先快速列出题名、类型、与任务的关系和全文可访问性，再按用户目标批次精读。用户要求每篇精读时持续逐篇推进。只有实际读完规定范围的文献才记作该范围已完成。
- 汇总优先写可以共同支持的结论、让结论改变的反例、很可能由条件不同引起的分歧，以及下一项能判别的证据。
- 用户要求写入笔记库时，用 DOI 查重，保留原记录以及历次范围、纠正和来源位置。用户提出“把写法学进 skill”时，把跨案例稳定的读图或写作决策写进对应能力参考，保留例证和例外。
